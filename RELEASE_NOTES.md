# Smart Guard v2.1

Public package of the original supplied **Smart Guard** battle mod for *Total War: WARHAMMER III*.

**Download:** `zzz_smart_guard_v2.1.zip` (contains `zzz_smart_guard.pack`).

### What it does
- Attempts to keep ranged units with Guard Mode enabled from advancing unnecessarily when ordered to attack.
- Uses battle Lua event handling and movement checks; no game executable modification.

### Installation
Extract the ZIP; place `zzz_smart_guard.pack` in the game's `data` directory, then activate it using a compatible launcher/mod manager.

**Epic Games compatibility is not yet verified in-game.** This package does not include **Always Enable Withdraw**, which is a separate mod.
